Lab Activity 1
Ephemeral State vs App State

This activity demonstrates the use of state management in Flutter.

The counter feature uses Ephemeral State with setState() because the data is only used inside one screen.

The theme feature uses App State with Provider because the data can affect the whole application.

Discussion
setState()
Used for simple data changes inside one screen.

Provider
Used for managing shared data that can be accessed by different parts of the application.
